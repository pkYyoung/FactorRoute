## 1. 目标与已确认决策

在现有 FactorRoute 仓库基础上增加本周研究成果，使队友既能看懂更新，也能按说明复现运行。采用适度整理，不重做整个框架。

1. 共用代码按功能组织，每周配置、报告和精选结果按计划持仓周归档，不每周复制程序。
2. GitHub 为公开仓库，只公开代码、配置、归一化研究结果及股票目标权重。账户资金、参考股数和下单预算留在本地。
3. 保留原有因子公式、IC 和 Top−Bottom 入口，本次不改变算法定义。
4. 清理已确认无后续价值的重复文件，先迁移验证再删除。
5. 保留 Git 历史，正常提交并推送 `main`；不创建 PR，不使用强制推送，不覆盖队友的新提交。

## 4. 程序边界和运行方式

### 4.1 原有框架

保留原有 `research_engine` 及其命令，保留原因子计算公式与参数。新增流程直接调用 `MomentumFactor/RSTR`、`ResidualVolatilityFactor/DASTD` 和 `BetaFactor/HBETA`，复用合适的原绩效函数，不再维护独立复制的公式。

组合回测需要纳入初始本金的回撤、明确的夏普定义和资金约束；这些适配放在新增组合模块，不通过本次整理悄悄改变原分组指标语义。

### 4.2 下载适配

`yfinance_source.py` 处理股票代码、行情请求、有限重试、缓存、供应商原始快照、参数、版本和校验和，输出统一研究输入。明确区分 Yahoo Close、Adj Close 和调整后研究开盘价；Close 本身也可能已按拆股调整，不能宣称等同历史交易所原始成交价。

保存股票池来源和获取时点，明确当前成分回看历史的偏差。缺少交易日、上市前空段和内部异常分别记录；禁止用填零或跨缺口填充掩盖错误。

### 4.3 评分和目标组合

`strategy/weekly.py` 读取配置并完成当日资格过滤、公司股类去重、MAD缩尾、标准化或排名评分、加权及选股。所有方向和权重在配置内声明；同分按证券代码确定顺序，并记录边界并列数量。

最终结果只保留当前评分和最终排名，不能把旧50/50的 `rank`、20只的 `target_weight` 混进70/30的10只结果。BETA保持风险观察用途。

### 4.4 日频模拟回测

`analysis/portfolio.py` 使用信号后首个交易日的调整研究开盘价进行差额调仓，持有期间按日收盘估值。成本按实际交易金额计，扣费后资金必须守恒。持仓价格缺失时停止并报告，不事后换股。

最新信号尚无未来开盘时，可以输出候选名单，但不能模拟买入；已有持仓仍估值至最后可用交易日。没有未来退出价格的区间不生成虚构收益。准确标注合成分数股、全额成交、公司行动和汇率等简化。

### 4.5 唯一周度入口

对外只介绍 `scripts/run_weekly.py`，由 `--config` 指定某周配置，使用明确的阶段参数执行下载、离线研究或完整流程：

```sh
python scripts/run_weekly.py --config experiments/weekly/2026-11-02/config.json --stage research
python scripts/run_weekly.py --config experiments/weekly/2026-11-02/config.json --stage download
python scripts/run_weekly.py --config experiments/weekly/2026-11-02/config.json --stage all
```

`research` 不联网，使用配置指向的本地快照；`download` 和 `all` 才访问数据源。未安装可选下载依赖时，离线研究仍可运行，下载阶段给出明确安装提示。

路径从项目根目录或配置位置解析，不写死某台机器的绝对路径。每次运行在本地新建结果目录，不覆盖既有实验；程序打印净值、回撤和图片位置，支持显式打开图片选项，便于VS Code运行。

周配置包含：信号日、下载起止（end排除）、股票池来源或本地名单、数据版本、分析与预热区间、因子/方向/权重、评分方法、持股数、流动性条件、成本、训练与复核分期。不包含账户资金和股数，不隐式搜索权重。

权重研究只作为同一入口的显式可选模式，记录候选集合、评价标准、风险筛选及分期；普通周运行使用冻结权重。保留本周六组比较证据，不能把探索后确定的25%筛选伪称为事前登记或未来止损保证。

## 7. 错误处理与验收

配置检查：权重有限、非负且和为1，持股数为正，日期合法，信号与行情时点一致。输入缺失、过期、成分覆盖不足或没有有效预热期时清楚报错，不生成貌似可用的名单。

必要验证：

- 原有合成研究链路继续通过，原CLI仍可用。
- 新合成样本验证周末信号/下个交易日入场、周内日估值、最新未完成持有区间。
- 对相同本地快照，迁移后的70/30、10只结果与迁移前实际保存的名单、净值和回撤一致；成本和收益口径一致。
- 检查每周公司去重、权重和、评分方向及排序，修改权重确实影响评分和选股。
- 截断未来数据不影响此前因子/组合路径；资金守恒、零波动价格不凭空盈利、未换仓不重复收费、最大回撤包含初始本金。
- 从项目根目录和不同当前工作目录运行入口，路径解析一致；离线模式不依赖网络；无未来价格时仍正确导出候选。
- Git暂存区逐项检查：没有行情、环境、凭据、账户金额、股数预算、本机路径或无关目录；精选图和指标与本周配置一致。

本次验收不声称解决历史成分、真正PIT数据、实盘交易、精确现金公司行动账本、行业上限或财报排除策略。这些是公开报告的已知限制和后续事项。
